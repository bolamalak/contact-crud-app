# Contact Management Application

## Description

A simple web application to manage contacts.

## Features

- Add contacts
- View contacts
- Edit contacts
- Delete contacts
- Search by name
- Pagination

## Technologies

- Python
- Flask
- MySQL
- PyMySQL
- HTML
- CSS
- Jinja

## Database

Database: contact_crud_app

Table: contacts
